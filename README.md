# Console based RPG game witten in C#

This project was developed for Object Oriented Design course during March-June 2025. The purpose of this project was to learn OOD principles and use design patterns in real project. 

The project is a simple RPG console game with no real purpose. The maps are generated by the program and contain different items and enemies. The player can collect items, equip armor, drink elixirs, collect coins and fight with enemies. 

The game also supports multiplayer game, by being designed as server-client.

## AI disclosure

The game was developed mostly by me. GitHub Copilot helped me by providing full-line code completion which was reviewed by me. All design pattern uses, ideas and approaches were mine.
